# 5강 개인 과제: 전투 시스템

기존 `Assets/Lesson03/Scenes/Lesson03Arena.unity` 씬에 전투를 추가했습니다.

## 실행

아레나 씬을 열고 Play를 누릅니다. WASD 이동, 마우스로 회전, Space 점프,
좌클릭 사격입니다. 체력이 0이 되면 게임이 멈추며 R로 재시작합니다.

## 구현

- 플레이어 체력 10, 화면 왼쪽 위 체력바
- 플레이어 총알: 피해 1, 속도 20, 수명 2초, 발사 간격 0.2초
- 근접 적: 체력 3, 감지 거리 15, 공격 거리 1.5, 1초마다 피해 1
- 원거리 적: 유지 거리 8, 사거리 12, 2초마다 총알 발사
- 시작 시 근접 적 5마리와 원거리 적 2마리
- 스포너: 3초마다 무작위 생성, 살아 있는 적 최대 10마리
- 기존 복셀 모델 두 종류 사용, 부모에만 태그/체력/모델 크기에 맞춘 콜라이더

`Models`에는 MagicaVoxel에서 직접 편집·저장한 VOX 원본과, 앱에서 내보낸 OBJ/MTL 및 색상 팔레트 텍스처가 있습니다.
Unity용 OBJ의 좌표는 기존 게임 크기에 맞춰 0.5배로 변환했습니다.
기존 이동, 점프, 맵은 유지했습니다. 강의 예제처럼 적은 직선으로 추적하며 벽을 통과합니다.
